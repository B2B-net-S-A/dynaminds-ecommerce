# Fala 1 integracji: luki w kodzie wobec scope v6 (25.10.2026)

Audyt statyczny bieżącego kodu `development/full-base` (commit `2cce639`, gałąź `goal/full-base-20261017`) dla 18 dostawców fali 1 i wszystkich 344 operacji integracyjnych z [scope.v6](scope.v6.json). Dane maszynowe: [integrations-wave1-gap-20261025.json](integrations-wave1-gap-20261025.json).

To jest stan kodu, nie odbiór. Testów nie uruchamiano, aplikacji, SQL ani HTTP do dostawców też nie. Każde odwołanie plik:linia sprawdzono w bieżącym drzewie. Statusy w scope v6 się nie zmieniają.

**Stany.** *Gotowe*: wywołanie dostawcy lub lokalny skutek jest w kodzie, osiągalne ze zwykłego API/UI/workera, i ma lokalny test z fake/fixture. *Częściowe*: kod istnieje, ale brakuje callsite, testu, części operacji albo deklaracji w rejestrze, albo transport jest wyłączony. *Brak*: nie ma kodu. *Czeka na dostawcę*: odbiór sandbox/konto wymaga konta, klucza albo umowy, których lokalnie nie ma.

- **KSeF bezpośrednio**: klient HTTP do MF istnieje (`server/ksef229-client.ts:11`), ale jest twardo wyłączony stałą `KSEF_REAL_ENABLED = false` (`:14`), a `ksefBaseUrl()` rzuca błąd przed każdym żądaniem (`:49`). - **Poczta Polska i DHL**: brak jakiegokolwiek kodu. - **Rozjazdy rejestru** (kod jest, rejestr mówi „planned” albo milczy): eBay `api.quota.provider.read`, Mirakl `orders.stage`/`orders.import`/`products.link.sku`/`api.rate.shared`, Fakturownia `correction.partial`, SMTP `email.inbound`, SMSAPI `sms.send`/`sms.delivery.callback`, Shopify `fulfillment.partial`. - **Bez konta dostawcy**: WooCommerce (pięć lokalnych oficjalnych sklepów, `tools/local/official-woo/compose.yaml`) i PrestaShop (sklep samohostowany, w repo brak fixture sklepu). KSeF ma środowisko testowe MF bez umowy, ale potrzebny jest token albo certyfikat dla NIP testowego.
